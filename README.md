# SysProg4 — однопроходный ассемблер (абсолютный формат)

Учебный проект по дисциплине «Системное программирование»: модель однопроходного ассемблера, транслирующего исходный текст на учебном ассемблерном языке в объектный (двоичный) код абсолютного формата. Приложение написано на C# (.NET 9) с графическим интерфейсом на WPF.

## Возможности

- Пошаговая трансляция исходного кода (кнопка **«Шаг»**) с отображением промежуточного состояния.
- Полный проход трансляции одной кнопкой (**«Первый проход»**).
- Редактируемая таблица кодов операций — набор команд можно менять прямо в интерфейсе.
- Отображение таблицы символических имён (ТСИ) с адресами меток и списком неразрешённых ссылок.
- Разрешение ссылок вперёд: обращение к метке до её объявления запоминается и подставляется, когда метка встречается в коде.
- Вывод понятных сообщений об ошибках трансляции (неверный формат команды, дублирование меток, переполнение памяти, отсутствие START/END и т.д.).

## Интерфейс

Главное окно разделено на панели:

| Панель | Назначение |
|---|---|
| Исходный текст | Редактор программы на учебном ассемблере |
| Таблица кодов операций | Список доступных команд в формате `ИМЯ КОД ДЛИНА` |
| ТСИ | Таблица символических имён: метка, адрес, неразрешённые ссылки |
| Двоичный код | Результат трансляции (записи H/T/E) |
| Ошибки | Сообщения об ошибках трансляции |

## Язык ассемблера

Строка исходного кода имеет вид:

```
[МЕТКА] КОМАНДА [ОПЕРАНД1] [ОПЕРАНД2]
```

Метка — до 10 символов, начинается с буквы, может содержать буквы, цифры и `_`; не должна совпадать с именами команд, директив и регистров.

### Директивы

| Директива | Назначение |
|---|---|
| `START адрес` | Начало программы и её загрузочный адрес (десятичное число, не 0); перед директивой обязательна метка — имя программы |
| `END [адрес]` | Конец программы и точка входа (по умолчанию — адрес начала) |
| `WORD значение` | Слово (3 байта), значение 1–16777215 |
| `BYTE значение` | Байт: число 0–255, строка `C"текст"` (ASCII) или hex-строка `X"1A2B"` |
| `RESW n` | Резервирование n слов (1–255) |
| `RESB n` | Резервирование n байт (1–255) |

### Команды (по умолчанию)

| Команда | Код | Длина |
|---|---|---|
| `JMP` | 1 | 4 |
| `INT` | 2 | 4 |
| `CALL` | 3 | 4 |
| `ADD` | 4 | 2 |
| `SUB` | 5 | 2 |

Формат операндов зависит от длины команды:

- **1 байт** — без операндов;
- **2 байта** — два регистра (`R1`–`R16`) или одно однобайтовое значение (0–255);
- **4 байта** — метка (прямая адресация) или трёхбайтовое значение (0–16777215).

Память модели ограничена 2²⁴ байт (адреса `0x000000`–`0xFFFFFF`), переполнение контролируется.

### Пример программы

```
PROG  START 1
      JMP   M2
M1    WORD  40
M2    BYTE  C"!"
M3    BYTE  12
      SUB   R1 R2
      ADD   R3 R4
      CALL  M1
      INT   200
      END
```

### Формат объектного кода

- `H имя адрес длина` — заголовок (имя программы, адрес загрузки, длина);
- `T адрес длина код` — тело (машинный код строки);
- `E адрес` — конец (адрес точки входа).

## Структура проекта

```
SysProg4/
├── SysProgTemplate/         # WPF-приложение (net9.0-windows)
│   ├── MainWindow.xaml(.cs) # Главное окно и логика UI
│   └── App.xaml(.cs)
└── SysProgTemplateShared/   # Библиотека логики ассемблера (net9.0)
    ├── Assembler.cs         # Ядро: трансляция, ТСИ, генерация кода
    ├── Helpers/
    │   ├── Parser.cs        # Разбор исходного текста и таблицы команд
    │   └── Comparer.cs      # Сравнение версий исходного кода
    ├── Structure/           # Command, CodeLine, Operand, SymbolicName
    ├── Dto/                 # CommandDto
    └── Exceptions/          # AssemblerException
```

## Сборка и запуск

Требуется [.NET SDK 9.0](https://dotnet.microsoft.com/download/dotnet/9.0) и Windows (приложение использует WPF).

```bash
dotnet build SysProgTemplate/SysProgTemplate.csproj
dotnet run --project SysProgTemplate/SysProgTemplate.csproj
```

Либо открыть проект в Visual Studio 2022+ и запустить `SysProgTemplate`.
